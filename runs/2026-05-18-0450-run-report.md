## Reflections / synthesis
Recent runs were external-research-driven and rotated through protocol / Netlink, native / ETW, and iOS / `AsyncStream`. That already satisfies the anti-stagnation requirement, but the KB still benefited from another source-backed practical pass because the protected-runtime deobfuscation branch had a real expression-level gap.

The practical mistake this run guards against is:

```text
MBA expression simplified == original behavior understood
```

The better proof ladder is:

```text
expression extracted
  != bit-vector domain / side effects frozen
  != candidate simplification produced
  != equivalence validated for the original domain
  != replacement safe at this program point
  != first semantic consumer / effect proved
```

Compact branch memory added:

```text
extracted != domain-frozen != simplified != equivalent != replaced != consumed/effected
```

This is a useful continuation below broad opaque-predicate / computed-next-state work and above durable state-edge or artifact-consumer proof.
