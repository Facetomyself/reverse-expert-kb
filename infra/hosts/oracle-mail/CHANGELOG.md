- 2026-04-18: Repaired an `Outlook Email Plus` inbound failure on `oracle-mail` that initially looked like a possible Cloudflare regression but turned out to be container-side outbound DNS drift. The public front door `mail.zhangxuemin.work` and host-side DNS were healthy, but `outlook-email-plus-app` could not resolve `login.microsoftonline.com`, which caused `GRAPH_TOKEN_EXCEPTION` / `EMAIL_PROXY_CONNECTION_FAILED` 502s when opening inboxes; `outlook-email-plus-caddy` simultaneously showed ACME renewal lookups timing out. Root cause: the running containers had inherited stale Docker resolver upstreams (`100.100.100.100`, with an old tailnet search domain) instead of the current OCI resolver. Remediation: added explicit `dns` entries (`169.254.169.254`, `1.1.1.1`) for both `app` and `caddy` in `/opt/outlook-email-plus/docker-compose.yml`, force-recreated the containers, then verified container-level resolution for both `login.microsoftonline.com` and `acme-v02.api.letsencrypt.org`; Caddy resumed successful ACME renewal-info fetches immediately after recreation.
