- SMJobBless sample material frames privileged-helper installation around least privilege, launchd-owned root-daemon execution, one-time authorization, and code-signing requirements that associate app and helper. Those are install / association boundaries, not later request-owned behavior proof.
- Search results surfaced `NSXPCListener.setConnectionCodeSigningRequirement(_:)`, `NSXPCConnection.setCodeSigningRequirement(_:)`, and low-level XPC peer-code-signing requirement APIs as identity-gate anchors. In reverse work, these should be placed relative to listener acceptance and method dispatch rather than treated as generic “XPC is safe/unsafe” labels.
- PID/name/proxy observations remain weaker reduction evidence unless the helper actually keys authorization to that material and reconnect / restart posture is understood.

## Reflections / synthesis
Recent autosync runs were all external-research-driven and rotated across native COM, deobfuscation MBA expressions, Linux Netlink, ETW, iOS `AsyncStream`, and Android A/B slot proof. The anti-stagnation requirement was already satisfied, but the branch still benefited from a source-backed practical refinement because the existing macOS ServiceManagement / XPC note had the broad helper ladder but needed a stronger client-identity/request-ownership stop rule.

The practical mistake this run guards against is:

```text
client proxy / listener acceptance / PID clue visible == trusted client-owned request proved
```

The sharper proof ladder is:

```text
client proxy created
  != listener accepted the connection
  != code requirement / audit-token / entitlement gate passed
  != the accepted client sent this behavior-bearing message
  != exported method entered with validated arguments
  != helper-owned effect happened under that trust decision
```

Compact branch memory added:

```text
proxy-visible != accepted != identity-gated != request-owned != method-entered != effect-owned
```

This is intentionally an extension of the existing native macOS helper page, not a new page: the source pressure narrowed a sub-boundary inside an already-canonical route rather than justifying another sibling leaf.
