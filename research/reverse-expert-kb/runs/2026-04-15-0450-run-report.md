## New findings
Primary durable split reinforced this run:

```text
same address/range visible
  != same storage contract still matters
  != same semantic object
  != same consequence-bearing incarnation
  != first-bad-write truth
```

A second compact split reinforced this run:

```text
real hit at watched location
  != current owner still points there
  != copy/rebind/reuse has not happened
  != later consequence still belongs to that incarnation
```

Concrete practical reinforcements preserved in the KB:
- GDB’s watchpoint docs explicitly distinguish watching an expression from `watch -location`, allow pointer-shaped expressions to become valid later, and delete local-variable watchpoints when scope ends; that is strong source-backed support for keeping expression validity, location truth, and object lifetime separate
- LLVM/Apple LLDB command-map material explicitly distinguishes variable watchpoints from memory-location / expression watchpoints and notes pointer-sized default monitoring for raw location watches; that supports the operator rule that a truthful memory-location watch can still follow stale storage
- Microsoft’s WinDbg `ba` docs define access breakpoints over an aligned address range plus explicit size and note processor-dependent overlap behavior; that makes `ba` a bounded location/range fact first, not an automatic object-identity fact
- Microsoft’s TTD docs expose `Memory(...)`, `MemoryForPositionRange(...)`, `PinObjectPosition(...)`, thread `UniqueId`, `Lifetime`, and `ActiveTime`; that directly supports pairing address-range queries with stronger time-pinned identity anchors instead of narrating continuity from raw address alone

- pair address-range watch/query results with one stronger identity anchor such as owner pointer, heap lifetime, slot generation, handle lifecycle, thread `UniqueId`, or a pinned trace position
- stop at the first copy/rebind/reuse boundary when address truth and object truth diverge; rename the result honestly as old-storage / pre-rebind / stale-slot truth instead of forcing continuity
- reopen first-bad-write work on the **current meaningful incarnation** only
